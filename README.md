# Ski Notes

A handwriting notes app for Android built around the Samsung S Pen.

- Pressure-sensitive pens: fountain, ballpoint, pencil, calligraphy, highlighter
- Low-latency inking (unbuffered input, every pen sample, predicted tail)
- S Pen button: hold to erase / lasso / highlight (choose in S Pen settings)
- Hover preview of brush size; palm rejection (fingers scroll and zoom)
- Ruler for straight lines (drag with one finger, twist with two, snaps to 15° steps)
- Hold at the end of a stroke to straighten it
- Stroke and area eraser, lasso select (move, resize, recolour, duplicate, delete)
- Lined / grid / dotted / blank paper, white / cream / dark
- Share as PDF or image

Every push builds `SkiNotes.apk` on GitHub Actions and publishes it under **Releases**.
